Shaliach vs OpenDots

CopilotKit's OpenDots and Shaliach both answer OpenAI dots the same way: always-on AI coworkers on hardware you control, each with its own computer. They differ in what you get. OpenDots is a template you build your own workspace from; Shaliach is a finished team of Claude Code agents you run from your phone.

Atlas, the short answer: If you are a developer who wants to build your own agent product, with any OpenAI-compatible model, Slack and an MIT licence, start from OpenDots. If you want a team that already works, on Claude Code, with approvals on your phone and one memory for every agent, that is Shaliach.

Which one fits

Pick OpenDots if

  • you want a codebase to build your own agent product on
  • you want any OpenAI-compatible model, or Slack as the front door
  • you need an MIT licence

Pick Shaliach if

  • you want a team that works today, with a chief of staff that hires it
  • you want Claude Code specifically, on the Claude plan or API key you already have
  • you want risky steps to wait for a tap on your phone
  • you want a correction to one agent to reach them all

Questions

Is Shaliach an OpenDots alternative?

Yes, if you want a finished app rather than a template. Both are self-hosted and give each agent its own computer. OpenDots is a starting point you clone and build on; Shaliach is a running team of Claude Code agents with a chief of staff, a Mac app and an iPhone app.

Which model does each use?

OpenDots talks to an OpenAI-compatible model provider you configure. Shaliach runs Claude through the official Claude Code CLI, on your own Claude account or Anthropic API key.

What are the licences?

OpenDots is MIT-licensed. Shaliach is closed source: a paid product, for businesses only.
